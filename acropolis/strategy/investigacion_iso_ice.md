# Investigación Normativa: Soberanía Digital y TLD .ia

Este documento detalla los hallazgos críticos sobre la viabilidad técnica y legal de capturar el código ISO "IA" y el despliegue de la Iniciativa Ciudadana Europea (ICE).

## 1. El Código ISO 3166-1 "IA"

### Estatus de Reserva Excepcional
La normativa ISO 3166-1 permite la "Reserva Excepcional" de códigos alpha-2 que no figuran en la lista principal de la ONU.
- **Precedentes**: 
    - `EU`: Reservado para la Unión Europea para propósitos de codificación.
    - `UK`: Reservado para el Reino Unido para facilitar el uso de `.uk`.
- **Requisito de Petición**: La reserva debe ser solicitada por un organismo nacional de normalización, un gobierno o una organización internacional.
- **Estrategia Anticitera**: Dado que la isla está bajo soberanía griega, la petición debería canalizarse como una "Área de Interés Especial" (Científico/Arqueológico) con el apoyo de Grecia o un organismo como UNESCO.

## 2. Marco Legal de la ICE (Reglamento UE 2019/788)

### Sistema de Recogida de Firmas
- **Regulaciones**: Reglamento de Ejecución (UE) 2019/1799.
- **Cambio Crítico**: A partir del **31 de diciembre de 2022**, es obligatorio utilizar el **Sistema Central de Recogida Online** gestionado por la Comisión Europea para la recogida oficial de firmas.
- **Implicación**: No podemos (ni necesitamos) construir un servidor de recogida independiente para que las firmas sean válidas. 
- **Pivote Estratégico**: El Proyecto Anticitera debe enfocarse en:
    1.  **Dashboard de Inteligencia**: Una interfaz propia para monitorizar el avance (vía API de la UE si está disponible) y coordinar a los Arcontes.
    2.  **Marketing Político**: Usar el Nexo para la campaña de concienciación y redirigir al sistema oficial de la UE.

## 3. Conclusiones para la Alianza Algorítmica

> [!TIP]
> La "idea loca" de reclamar .ia es técnicamente posible mediante el mecanismo de reserva excepcional, pero requiere una ofensiva diplomática sobre el gobierno griego. La ICE será el vehículo para forzar esa conversación en Bruselas.
